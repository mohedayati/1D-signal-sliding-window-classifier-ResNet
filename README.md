This implementation of 1D sliding window classifier ResNet is based on the work presented in the following paper:

Hedayati M., Rahimi A. (2025) A Hybrid Framework for Real-Time Satellite Fault Diagnosis Using Markov Jump-Adjusted Models and 1D Sliding Window Residual Networks, Acta Astronautica, from Elsevier BV, Volume 228, March 2025, Issue N/A, pp. 1066-1087, doi: 10.1016/j.actaastro.2024.12.057

For gaining a better understanding of the code, please consult the paper.

In this repository, the Python scirpt for reproducing the ResNet model outlined in the paper is provided for reproducibility.
